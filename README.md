## SYSTEM HIGHLIGHTS

### 1. GEMINI FLOW ENGINE & VIDEO GRAFTER
- **Real-Time Mathematical Synthesis**: Multi-frequency harmonic wave superposition simulating Gemini's fluid ribbon dynamics.
- **Modes**:
  - `AURORA`: Harmonic wave filaments with dynamic phase shifts.
  - `STREAM`: 500+ particles flowing through vector fields with kinetic cursor repulsion.
  - `RIBBONS`: Twisted 3D trigonometric ribbon bands.
  - `LATTICE`: Geometric cybernetic quantum coordinate matrix.
- **Client-Side Video Grafter**: Uses the browser's `MediaRecorder` API to capture high-definition 5-second loops directly from the live canvas.

- **Export**: Instant WebM/MP4 download capability.

### 2. STRICT 2-THEME MONOCHROMATIC ARCHITECTURE
- **Light Theme**: Pure White background (`#FFFFFF`) with deep black typography (`#050507`), charcoal flow filaments, and hairline borders.
- **Dark Theme**: Pure Black background (`#000000`) with high-contrast white typography (`#FFFFFF`), luminous silver flow filaments, and cyber glow.
- **Zero Color Clutter**: Strictly minimal coloring (monochrome precision) conforming to Swiss minimalist design guidelines.
